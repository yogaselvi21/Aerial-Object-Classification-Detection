# Aerial-Object-Classification-Detection

🦅 Aerial Object Classification & Detection 🛰️

📌 Project Overview:

This project delivers a deep learning solution to classify and locate birds and drones in aerial imagery. It enhances security surveillance, wildlife protection, and airspace safety by accurately distinguishing between biological and mechanical flying objects.

🚀 Features

Custom CNN: Lightweight convolutional neural network built from scratch for binary classification.

Transfer Learning: Advanced feature extraction utilizing pre-trained state-of-the-art models.

Object Detection: Real-time localization and labeling powered by YOLOv26.

Interactive Web App: User-friendly Streamlit interface for instant image uploads and model predictions.


🗂️ Project Structure

Mini_Project_5_Object_Classification_Pytorch.ipynb: Implements custom CNN design and transfer learning workflows for binary classification using PyTorch.

Mini_Project_5_Object_Classification_TensorFlow.ipynb: Implements custom CNN design and transfer learning workflows for binary classification using TensorFlow.

Mini_Project_5_Object_Detection.ipynb: Implements and evaluates a real-time YOLOv8 model to locate and label objects.


📈 Results

TensorFlow (ResNet50): Achieved a peak classification accuracy of 99.62%.

PyTorch (ResNet50): Achieved a strong classification accuracy of 96.38%.
